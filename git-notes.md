# Git command notes
this file contains useful Git commands

Git is a version control system that helps developers track their changes in their projects and collaborate with others

1.Git status
shows the current state of the working directory and staging area

2.Git add
stages changes for the next commit

3.Git commit
saves staged changes as a checkpoint in git history

4.Git log
displays the history of commits

5.Git diff
shoes the changes made to files

6.git clone
downloads a remote repository to your computer

7.Git push
uploads local commits to a remmote repository

8.Git pull
fetches and integrates changes from a remote repository

9.Git fetch
downloads updates from a remote repository without merging them

10.Git branch
lists branches or creates a new branch

11.Git switch
switches from one branch to another 

12.Git restore
discards unstaged changes in a file

steps
1 check changes using git status
2 stage a file using git add and REDAME.md
3 commit changes using git commit -m 
4 upload commits using git push
5 check commit history using git log --oneline
